# Inglês do Zero — Plataforma de Estudos

## Como abrir
1. Baixe e extraia o ZIP.
2. Abra a pasta `ingles-do-zero` no VS Code.
3. Abra `index.html` no navegador. Também pode usar a extensão Live Server.

## Estrutura
- `index.html`: estrutura do site.
- `css/style.css`: aparência e responsividade.
- `js/app.js`: conteúdo, exercícios e progresso.

## Recursos
- Painel inicial com progresso.
- Módulo 1 com cinco aulas.
- Explicações em português, exemplos em inglês e pronúncia aproximada.
- Vocabulário com pesquisa.
- Diálogos para conversação.
- Exercícios interativos com correção.
- Leitura com tradução.
- Progresso salvo no navegador com localStorage.

## Observações
O progresso fica salvo no navegador e dispositivo utilizados. Se limpar os dados do navegador, poderá ser apagado. Os links de vídeo abrem pesquisas no YouTube. Os módulos seguintes estão indicados como próximos passos e serão desenvolvidos gradualmente.
